# CYBER Web Golden Path Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a deterministic, accessible, bilingual React Web prototype that takes an authorized Web-lab task from scope review through Allow/Deny execution, recovery, Finding/Evidence inspection, report freeze, and export.

**Architecture:** A pnpm workspace contains typed shared protocol contracts, a pure event projector, an EventSource-shaped deterministic scenario player, reusable Forensic Noir UI primitives, and a Vite Web app. The UI renders only `ProductState`; it never becomes an authority for scope, approval parameters, Evidence, cursors, or report integrity. Mock local and remote sources implement the same interfaces so Phase 4 can replace them without changing the product contract.

**Tech Stack:** Node.js `>=22.12.0`; pnpm `10.15.1`; React/React DOM `19.1.1`; TypeScript `5.9.2`; Vite `7.1.3`; `@vitejs/plugin-react` `5.0.2`; Vitest `4.0.7`; React Testing Library; `vitest-axe`; Playwright Test `1.61.0`; ESLint `9.34.0` with `typescript-eslint` `8.41.0`; Radix Dialog/Tabs/Popover/Tooltip; `pdf-lib`; plain CSS and CSS custom properties. Vite 7 is intentional because it supports Node 22 and TypeScript 5.9 without requiring the TypeScript 6 toolchain used by Vite 8 templates.

## Global Constraints

- Scope is Phase 1 Web prototype only; do not implement Tauri native integration, Go TUI redesign, embedded terminal, real runtime sources, Monaco, graphs, teams, production remote authentication, or public-target testing.
- Use pnpm workspaces and root scripts; do not add Turborepo or Nx.
- Use exactly Node.js `>=22.12.0`, pnpm `10.15.1`, React/React DOM `19.1.1`, TypeScript `5.9.2`, Vite `7.1.3`, `@vitejs/plugin-react` `5.0.2`, Vitest `4.0.7`, `@playwright/test` `1.61.0`, ESLint `9.34.0`, and `typescript-eslint` `8.41.0`; package manifests must use exact versions without `^` or `~`.
- Use React + TypeScript + Vite, Vitest, React Testing Library, `vitest-axe`, `@axe-core/playwright`, and Playwright Test. Runtime React axe instrumentation is out of scope.
- Use `pdf-lib` for PDF output; PDF tests must assert the generated bytes begin with `%PDF-`.
- The only scenario target is the explicitly authorized local laboratory `juice-shop.lab`; never use a real public target.
- Runtime authority is represented by immutable task scope snapshots, immutable approval challenges, trusted immutable Evidence, event cursors, and control-lease revisions; browser state cannot expand authority or approve modified parameters.
- Event IDs deduplicate, task cursors strictly increase, unknown events remain raw without speculative projection, and unsupported schema versions fail explicitly.
- Default UI language is Simplified Chinese with complete English translations; all UI copy uses i18n keys, while raw tool output is not automatically translated.
- Forensic Noir uses graphite/cool-gray surfaces, restrained mint accent, amber for pending/verification/medium risk, and red only for failure/blocking/severe Findings; never use neon glow, glassmorphism, or color-only meaning.
- WCAG AA is mandatory: keyboard-only primary flow, skip link, visible focus, semantic names, dialog focus trap/restoration, non-color state encoding, AA contrast, and `prefers-reduced-motion`.
- Phone layout supports observation, key Findings, notifications, normalized approval inspection, Allow/Deny, pause, and cancel only; it does not create complex scopes, edit reports, compare large Evidence, analyze graphs, or operate a local workspace.
- Every task below is independently reviewable, must use TDD, and ends with a focused commit. Do not add a co-author trailer to plan commit snippets.

```ts
  'control.transferred': { lease: ControlLease };
  'report.drafted': { report: ReportState };
  'report.frozen': { reportId: string; version: number };
}

export type KnownEventType = keyof KnownEventPayloads;
export type KnownProductEvent = {
  [K in KnownEventType]: ProductEvent<K, KnownEventPayloads[K]>
}[KnownEventType];
export type UnknownProductEvent = ProductEvent<string, JsonObject> & {
```

```ts
export type ConnectionStatus =
  | 'connecting' | 'healthy' | 'degraded' | 'reconnecting'
  | 'resyncing' | 'offline' | 'incompatible' | 'unauthorized';
export type ConnectionState = {
  status: ConnectionStatus;
  lastTrustedCursor: number;
  errorCode?: string;
};
export type RuntimeCommand =
  | { type: 'task.create'; objective: string; runtimeId: string; workspace?: string }
  | { type: 'scope.confirm'; scopeId: string }
  | { type: 'task.pause' }
  | { type: 'task.resume' }
  | { type: 'task.cancel' }
  | { type: 'approval.respond'; challengeId: string; decision: ApprovalDecision }
  | { type: 'control.take'; expectedRevision: number }
  | { type: 'instruction.send'; content: string };
export type RuntimeSnapshot = { cursor: number; state: ProductState };
export type Unsubscribe = () => void;
export interface EventSource {
  subscribe(afterCursor: number, onEvent: (event: RawProductEvent) => void): Promise<Unsubscribe>;
  getSnapshot(): Promise<RuntimeSnapshot>;
  send(command: RuntimeCommand): Promise<void>;
  close(): Promise<void>;
}
export type RuntimeView = { connection: ConnectionState; product: ProductState };
```
