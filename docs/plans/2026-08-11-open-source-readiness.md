# 开源化实施计划

> 执行方式：每项完成后运行针对性检查；最终运行完整验证矩阵。

- [ ] 更新 `README.MD`：定位、状态边界、安装/运行、架构、开发、贡献、许可证和安全入口。
- [ ] 添加 `LICENSE`：Apache License 2.0 完整文本。
- [ ] 添加 `CONTRIBUTING.md`：环境、分支、测试、提交和 PR 规范。
- [ ] 添加 `SECURITY.md`：私下报告流程、支持范围、授权测试和凭据处理要求。
- [ ] 添加 `CODE_OF_CONDUCT.md`：Contributor Covenant 2.1。
- [ ] 添加 GitHub issue 表单和 PR 模板。
- [ ] 校验 Markdown 链接、许可证年份/版权主体和模板 YAML 结构。
- [ ] 运行 `pnpm test`、`pnpm typecheck`、`pnpm build`、`go test ./...` 及现有 shell 检查。
- [ ] 仅提交开源化文件，推送 `docs/open-source-readiness` 到 `cyber-code-private`。
- [ ] 创建关联 tracking issue 和目标为 `main` 的 PR，记录验证结果与剩余平台限制。
